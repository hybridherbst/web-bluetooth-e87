# E87 Studio 1.0.0-beta.1

## English

A community desktop edition of [web-bluetooth-e87](https://github.com/hybridherbst/web-bluetooth-e87), based on Felix Herbst's MIT-licensed protocol implementation. This is a **preview from the contributor's fork**, not an official upstream release.

### Included

- A compact offline editor with circular preview, explicit Bluetooth device selection, saved names and MAC addresses.
- Images, slideshows, short video, QR codes and scrolling text with Cyrillic/Latin support.
- Eight procedural visuals: Liquid chrome, Pearl, Crimson silk, Aurora, Dichroic, Gold eclipse, After dark and Contour; the 12 original patterns remain available.
- macOS advertisement-based MAC discovery. Chromium's UUID-derived ID is never presented as the hardware MAC on Mac.
- English and Russian documentation, local JPEG/AVI export, file-format guidance and a 2,000,000-byte payload limit.

The app's interface is currently **Russian**. The original browser UI and shared BLE/authentication/AVI code remain unchanged; the desktop UI has its own build entry point.

### Choose a download

| Platform | File | Use |
| --- | --- | --- |
| macOS | `.dmg` or `.zip` | Install the app; check `arm64` / `universal` in the filename |
| Windows x64 | `-setup.exe` | Installer with destination choice |
| Windows x64 | `-portable.exe` | Run without installation |
| Linux x64 | `.AppImage` | Portable application; FUSE may be required |
| Linux x64 | `.deb` | Debian/Ubuntu package |

`SHA256SUMS.txt` records the checksum of each attached installer. Source is available from this release's tag and the source archives generated by GitHub.

### Validation and limitations

Svelte/TypeScript checks, six regression tests and separate browser/desktop production builds are part of the build process. Packaging success is not hardware validation. E87 connection, a 360 × 360 screen query and advertised MAC identification were tested on macOS / Apple Silicon during development. Windows/Linux Bluetooth, Intel Mac runtime behavior and all firmware variants still need hardware testing. No claim is made that every generated animation has been played on every badge.

The builds have no commercial signing certificate: Mac is ad hoc signed and not notarized; Windows has no Authenticode signature. OS warnings may appear. Linux requires BlueZ, D-Bus and a compatible BLE adapter. The Chromium sandbox stays enabled.

Start with [the English guide](../../README.md) for pairing, formats, architecture and source-build commands. Please report OS, adapter, badge firmware if known, and a redacted log when reporting a problem; do not include private MAC addresses unnecessarily.

## Русский

Настольная версия [web-bluetooth-e87](https://github.com/hybridherbst/web-bluetooth-e87) на основе реализации протокола Феликса Хербста, лицензия MIT. Это **предварительная сборка из fork автора PR**, пока не официальный выпуск исходного проекта.

### Возможности

- Компактный локальный редактор с круглым предпросмотром, явным выбором Bluetooth-устройства, сохранением имён и MAC.
- Картинки, слайд-шоу, короткие видео, QR-коды и бегущая строка с кириллицей и латиницей.
- Восемь новых анимаций: Liquid chrome, Pearl, Crimson silk, Aurora, Dichroic, Gold eclipse, After dark и Contour; доступны и 12 исходных эффектов.
- На Mac адрес читается из Bluetooth-объявления поддерживаемых E87. Служебный ID Chromium не выдаётся за аппаратный MAC.
- Документация на двух языках, экспорт JPEG/AVI, подсказки по форматам и ограничение готового файла в 2 000 000 байт.

Интерфейс приложения сейчас **на русском**. Исходный веб-интерфейс, протокол BLE, авторизация и создание AVI сохранены. Настольная версия собирается отдельно.

### Что скачать

Для macOS — DMG или ZIP, с подходящей архитектурой в имени. Для Windows x64 — установщик `setup.exe` или `portable.exe` без установки. Для Linux x64 — AppImage или DEB. Контрольные суммы установщиков находятся в `SHA256SUMS.txt`, исходники — в теге релиза и стандартных архивах GitHub.

### Что проверено

В процессе сборки выполняются проверки Svelte/TypeScript, шесть регрессионных тестов и отдельная сборка веб- и настольного интерфейсов. При разработке на Mac / Apple Silicon проверены подключение к E87, чтение размера экрана 360 × 360 и определение настоящего MAC. Bluetooth на Windows/Linux, запуск на Intel Mac и разные прошивки требуют аппаратной проверки. Успешная сборка не гарантирует совместимость с каждым значком.

Коммерческой подписи нет: Mac подписан ad hoc без нотариализации; Windows — без Authenticode. Возможны предупреждения ОС. Linux требует BlueZ, D-Bus и BLE-адаптер. Sandbox Chromium остаётся включён.

Подключение, форматы, устройство кода и команды сборки описаны в [русской инструкции](../../README.ru.md). В сообщении об ошибке укажите ОС, адаптер, прошивку при наличии и журнал без личных данных.
