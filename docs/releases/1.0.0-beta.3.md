# E87 Studio 1.0.0-beta.3 — JPEG and photo cropping / JPEG и обрезка фото

## English

Fixes a format difference introduced by the native desktop app: macOS WebKit's
canvas JPEG encoder inserts restart markers at every 16-pixel MCU row. Chromium's
encoder used in the earlier Electron app does not. The reported symptom on two
badges was a correct strip at the top followed by stripes.

All desktop output now uses one bundled Rust JPEG encoder: baseline, 8-bit YCbCr
4:2:0, without restart markers, including at high quality. This covers images,
QR codes, effects, scrolling text, slideshows and every Motion JPEG AVI frame.
Pixels and encoded files cross the native bridge as binary data. No external
codec installation is needed. The BLE protocol is unchanged.

AVI headers now also use the selected badge's output dimensions, including
360×360 devices, rather than always declaring 368×368.

Photo import retains the entire image instead of discarding everything outside
the central square. Drag to position any part of the photo inside the badge's
circle, including the ends of panoramas. Aspect ratio is preserved, zooming out
can fit the entire photo, and the preview/export share the same framing. Pointer
movement now accounts for the displayed canvas size.

Regenerate and resend files created with beta.2; exporting them again with the
old app preserves the incompatible encoding. Tests check JPEG headers at all
quality ranges and ensure the desktop never falls back to WebKit encoding.
The reporting user gives initial positive feedback on badge playback from the fixed Apple Silicon build. Broader device/firmware coverage, Windows/Linux BLE and Intel Mac runtime behavior still require hardware testing.

## Русский

Устранено различие формата после перехода на native: кодировщик macOS WebKit
добавлял в JPEG маркеры перезапуска каждые 16 строк. В Chromium, который использовала
прежняя Electron-сборка, этих маркеров нет. На двух значках пользователь видел
правильную полоску сверху и полосы на остальном экране.

Теперь все картинки и кадры анимаций в настольном приложении кодируются одним
встроенным кодировщиком Rust: обычный JPEG, 8 бит, YCbCr 4:2:0, без маркеров
перезапуска, в том числе при высоком качестве. Исправление охватывает картинки,
QR-коды, эффекты, бегущую строку, слайд-шоу и видео. Дополнительные кодеки не нужны.
Протокол Bluetooth не менялся.

Размер кадра в заголовках AVI теперь также соответствует значку, в том числе
360×360, вместо постоянного значения 368×368.

Фотография при загрузке сохраняется целиком. Её можно свободно двигать под кругом,
включая края панорам, без предварительной обрезки в другом редакторе. Пропорции
сохраняются, уменьшение позволяет поместить в круг весь снимок, а предпросмотр
совпадает с экспортом. Перетаскивание учитывает фактический размер окна просмотра.

Файлы, подготовленные в beta.2, нужно заново создать из исходников и отправить
из новой версии. Автоматические проверки контролируют формат JPEG и отсутствие
возврата к кодировщику WebKit. От пользователя получен первый положительный отзыв о воспроизведении на значке из исправленной сборки Apple Silicon. Другие прошивки, Bluetooth на Windows/Linux и запуск на Intel Mac ещё требуют аппаратной проверки.
