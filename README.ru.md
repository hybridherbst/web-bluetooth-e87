## Подключение

1. Включите Bluetooth на компьютере. На значке откройте Bluetooth/QR-экран.
2. Отключите значок в ZRun и на сайте, если они уже держат соединение.
3. Нажмите **Подключить**. Выберите устройство в списке.
4. Сохраните понятное имя. Если ОС скрывает MAC, введите адрес с экрана значка или вставьте содержимое его QR-кода. Ссылка разбирается локально и не открывается.
5. Выберите контент, проверьте круглый предпросмотр и нажмите **На значок ↗**. Держите значок рядом до окончания передачи.

При нескольких одинаковых E87 включайте режим подключения по одному, назначая каждому имя. Приложение не выбирает первое попавшееся устройство автоматически.

Приложение читает настоящий MAC из manufacturer data E87 (`0x6DB9`), если прошивка его передаёт. На Mac UUID CoreBluetooth показан отдельно и не выдаётся за MAC. На Windows/Linux дополнительно может быть доступен системный адрес Bluetooth. Для неизвестных прошивок остаётся ручной ввод: сохранённый адрес служит подписью, а не способом подключения к отсутствующему в поиске значку.

Имена и адреса сохраняются локально. «Забыть» удаляет запись, не содержимое значка. После перехода с Electron beta имена и настройки нужно ввести заново: системный WebView использует другое хранилище. Старые данные не удаляются.

## Файлы

| Режим | Вход | Что передаётся |
| --- | --- | --- |
| Картинка | PNG, JPEG/JPG, WebP, BMP; GIF как один статичный кадр | JPEG |
| Слайд-шоу | Несколько картинок, упорядоченных по имени с числовой сортировкой | AVI / Motion JPEG |
| Видео | MP4/H.264; WebM зависит от системных кодеков | AVI / Motion JPEG без звука |
| Бегущая строка | Текст до 80 символов, кириллица; шрифт, размер, цвет, фон, скорость и направление | AVI / Motion JPEG |
| Эффекты | 8 новых материалов Studio и 12 классических генераторов | JPEG или AVI |
| QR-код | Текст ссылки | JPEG |

- До подключения размер кадра — 368 × 368. После подключения размер запрашивается у значка.
- Важные элементы должны помещаться в круг. Картинку можно двигать мышью и масштабировать колесом.
- Готовая передача ограничена **2 000 000 байт** (около 1,91 МиБ), исходный файл может быть больше.
- Видеофрагмент — до 10 секунд. Если результат велик, уменьшите длительность или частоту кадров. Для начала удобно 12 fps.
- В слайд-шоу 1 fps означает один кадр в секунду. Имена `01.png`, `02.png`, `03.png` помогают задать порядок.
- MOV, HEVC и другие кодеки зависят от декодеров системного WebView/ОС; расширение файла само по себе не гарантирует совместимость. Перекодируйте неподдерживаемый ролик в MP4/H.264.
- **Сохранить** экспортирует подготовленный JPEG/AVI. Это не экспорт редактируемого проекта. AVI можно выбрать в режиме видео, если системный декодер его поддерживает.
- ZIP, JSON, программы и исполняемые «сценарии» не загружаются. Анимация здесь — последовательность кадров.

## Бегущая строка и коллекция Studio

Текст движется влево или вправо; доступны гротеск, антиква и моноширинный шрифт, размер 48–120 px, три скорости, цвет и свечение. Предпросмотр обновляется после ввода. Цикл ограничен 240 кадрами при 15 fps; если надпись длинная, приложение предложит увеличить скорость, уменьшить размер или сократить текст.

Новые эффекты: **Liquid chrome**, **Pearl**, **Crimson silk**, **Aurora**, **Dichroic**, **Gold eclipse**, **After dark** и **Contour**. Это локально генерируемые циклы, а не скачанные видео. Выберите 3, 5, 6 или 8 секунд; для статичного аксессуара переключитесь на «Кадр». Классические 12 эффектов доступны отдельно.

Основное окно — 920 × 720, справка спрятана под «?», сохранённые MAC и имена — под «Значки».

## Установка и платформы

- **macOS 12+:** DMG для Apple Silicon или Intel, приложение перенести в Applications. При подключении разрешите Bluetooth. Встроенного браузера, Python и отдельного помощника нет.
- **Windows 10/11 x64:** установщик `.exe`. Используется системный Microsoft Edge WebView2; если его нет, установщик скачает его. Такая первая установка требует интернета и дополнительного места, не включённого в размер нашего установщика. Нужны BLE-адаптер и драйвер.
- **Linux x64:** DEB через пакетный менеджер с разрешением зависимостей. Используются общие WebKitGTK 4.1, GTK 3, BlueZ и D-Bus; на минимальной системе их первая загрузка может весить заметно больше приложения. Целевые системы — Ubuntu 22.04+ и совместимые Debian-дистрибутивы. Для остальных доступна сборка из исходников. Видеокодеки зависят от GStreamer. Chromium и экспериментальные флаги Web Bluetooth больше не нужны.

Сборки сообщества: Mac подписан ad hoc без нотариализации, Windows без коммерческого сертификата. Возможны предупреждения ОС. Нативный Bluetooth в beta.2 новый, аппаратные проверки предыдущей Electron-версии на него не распространяются. Успешная сборка не заменяет проверку на железе.

## Разработка и сборка

Нужны Node.js 22.16+, npm, stable Rust и [зависимости Tauri для вашей ОС](https://v2.tauri.app/start/prerequisites/): Xcode Command Line Tools на Mac, MSVC C++ Build Tools/WebView2 на Windows, WebKitGTK 4.1/GTK 3/D-Bus development packages на Linux. Версии закреплены в npm/Cargo lockfiles.

```sh
npm ci
npm run check
npm run build
cargo test --locked --manifest-path src-tauri/Cargo.toml
npm start
```

Сборка на соответствующей ОС:

```sh
npm run dist:mac
npm run dist:win
npm run dist:linux
```

Установщики — в `src-tauri/target/release/bundle/`. По умолчанию используется архитектура текущего компьютера. CI собирает отдельные пакеты Mac ARM64/Intel, Windows x64 и Linux x64. Явный target: `npx tauri build --target <target> --bundles <dmg|nsis|deb> -- --locked`; target нужно установить через rustup. CI сохраняет артефакты, публикация релиза выполняется отдельно.

`npm run build:web` собирает исходный веб-редактор в `web/dist/`. Настольный интерфейс использует `web/desktop.html` и `web/dist-desktop/`. В готовом приложении файлы встроены в исполняемый файл, локальный сервер не нужен. Исходный веб-интерфейс и протокол upstream сохранены.

## Если значок не находится

Оставьте QR-экран, проверьте Bluetooth и разрешение для E87 Studio. Завершите другие подключения. Не запускайте старую и новую версии одновременно. Поиск начинается только по кнопке и прекращается через две минуты. В журнале внизу окна видны подробности ошибки.

## Устройство кода

- `src-tauri/src/main.rs`: окно, системное сохранение, защита закрытия при передаче, локальная навигация.
- `src-tauri/src/bluetooth.rs`: CoreBluetooth / WinRT / BlueZ, поиск и MAC из объявлений, GATT, тайм-ауты и разбиение пакетов по MTU.
- `web/src/studio/native-bluetooth.ts`: небольшой адаптер Web Bluetooth для исходного протокола; выбор, уведомления, состояния соединения.
- `web/src/studio/native.ts`: ограниченный мост к нативным функциям и совместимость canvas.
- `web/src/studio/`: интерфейс, бегущая строка, 8 новых эффектов.
- `web/src/lib/e87-protocol.ts`, `jl-auth.ts`, `avi-builder.ts`: исходный код протокола, авторизации и AVI без изменений.

У интерфейса нет общего доступа к файлам, командной строке и удалённым страницам. Сохранение — через системный диалог в выбранный пользователем файл. Bluetooth-команды ограничены выбранным E87 и известными сервисами. Части пакета отправляются последовательно, без смешивания с автоматическими подтверждениями.

Тесты проверяют отмену и устаревшие результаты поиска, уведомления, границы массивов, отключение, MAC/QR и длительность текста. Rust-тесты проверяют адреса из объявлений, доступные сервисы и размер пакетов. Они не заменяют аппаратную проверку. Исходная документация полностью сохранена в [docs/PROTOCOL.md](docs/PROTOCOL.md).
